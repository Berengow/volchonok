# Волчонок Тучка: осенняя поляна

Маленькая браузерная игра для телефона: выбираешь подругу с ушками и гуляешь с ней по осенней поляне. Её можно гладить по голове, щёчкам и под подбородком, держать за руку, давать пять, обнимать, кормить, играть и укладывать спать. Пальцем по траве её можно повернуть.

Работает целиком в браузере на [three.js](https://threejs.org/) и [three-vrm](https://github.com/pixiv/three-vrm), без сервера и сборки.
